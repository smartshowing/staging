---
title: "System Modes"
---

The Smart Showing Kit operates in clearly defined modes that align with how a property is used throughout the listing period.  
Modes are managed as part of the service and adjusted as conditions change.

Each mode is designed to be predictable, intentional, and appropriate to the situation.

## Stage Mode

Stage Mode is used during active showings.

In this mode, the system supports normal interior movement while maintaining awareness of entry, exit, and activity in key areas. It allows the property to be shown naturally without interruption.

Stage Mode provides:
- Confirmation of arrival and departure
- Interior awareness during the showing
- Accountability without intrusion

This mode is optimized for open houses, scheduled showings, and guided walkthroughs.

## Security Mode

Security Mode is used when the property is vacant or not expected to have interior activity.

In this mode, the system focuses on early detection of unexpected entry or movement. It is designed to identify activity that falls outside of normal showing behavior and respond accordingly.

Security Mode provides:
- Continuous vacant-home protection
- Awareness of unexpected access
- Early detection between showings

This mode operates 24/7 when the property is unoccupied.

## Disabled Mode

Disabled Mode is used when monitoring is not desired.
