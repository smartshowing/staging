---
title: "System Modes"
---

The Smart Showing Kit operates in clearly defined modes that align with how a property is being used.

Modes allow the same installed system to support an occupied home, active property showings, vacant-home protection, or temporary suspension of system activity.

Each mode is designed to be predictable, intentional, and appropriate to the situation.

## Living Mode

Living Mode is used while the seller or other occupants are living in the property.

In this mode, Smart Showing can continue to provide useful household features while remaining ready to support the listing.

Living Mode may provide:

- Calendar-based voice reminders
- Family and household reminders
- Upcoming showing notifications
- Contractor, inspection, and appointment reminders
- Selected lighting and audio automation
- Other configured convenience features

Authorized users may include both the homeowner and real estate agent.

For example, a real estate agent may schedule reminders for an upcoming showing, photographer, inspector, or contractor, while the homeowner may use the same system for school schedules, pickups, appointments, or other family activities.

Living Mode allows Smart Showing to provide value even while the property remains occupied.

## Showing Mode

Showing Mode is used during active showings, open houses, and authorized property visits.

In this mode, the system supports normal interior movement while maintaining awareness of entry, exit, and activity in key areas.

Showing Mode may provide:

- Confirmation of arrival and departure
- Interior awareness during the showing
- Customized lighting
- Welcome messages and property narration
- Showing instructions
- Accountability without unnecessary intrusion

This mode is designed to support a natural showing experience while maintaining appropriate property awareness.

## Security Mode

Security Mode is used when the property is vacant or interior activity is not expected.

In this mode, the system focuses on early detection of unexpected entry or movement.

Security Mode provides:

- Continuous vacant-home protection
- Awareness of unexpected access
- Early detection between showings
- Configurable alerts and responses

Security Mode may operate continuously whenever the property is unoccupied.

## Disabled Mode

Disabled Mode is used when Smart Showing functions are temporarily not desired.

Devices may remain installed, but configured monitoring, narration, reminders, or automation functions can be suspended.

Disabled Mode may be used when:

- The homeowner requests a temporary pause
- Installation or maintenance work is underway
- The property is transitioning between uses
- Smart Showing functions are temporarily unnecessary

The system can later return to Living, Showing, or Security Mode without requiring a new installation.
