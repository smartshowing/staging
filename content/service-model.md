---
title: "Service Model"
---

The Smart Showing Kit is provided as a fully managed service.  
It is not sold, self-installed, or self-managed.

This service model ensures consistency, reliability, and appropriate use throughout the listing period.

## Installation

The system is professionally installed at the start of the listing or agreed showing window.

Installation includes:
- Device placement aligned with the property layout
- System testing and verification
- Mode configuration based on how the property will be used

No permanent modifications are made to the property.

## Ongoing Management

Once installed, the system is managed continuously as part of the service.

This includes:
- Monitoring system health
- Managing system modes
- Handling notifications and responses
- Adjusting configuration as listing conditions change

Agents and sellers are not responsible for system operation.

## Support During the Listing

Support is available throughout the active listing period.

If questions arise regarding:
- Access confirmation
- System behavior
- Notifications or alerts

They can be addressed without requiring the agent or seller to troubleshoot or visit the property.

## Removal

When the listing concludes or the service period ends, the system is professionally removed.

Removal includes:
- Device removal
- Verification that no equipment remains
- Clearing of temporary operational data

The property is returned to its original condition.

## Why a Managed Model Matters

A managed service model:
- Reduces the risk of misconfiguration
- Ensures appropriate use
- Protects both agent and seller
- Justifies the initial setup and ongoing service cost

The value of the Smart Showing Kit is realized through time savings, reduced travel, and consistent oversight—made possible by professional management.
