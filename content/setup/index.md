# 🏡 Smart Showing™ Setup Guide

Welcome!  
Your Smart Showing™ system is pre-configured and ready to use.

Setup takes about **5–10 minutes**.

---

## 📦 What You Need

- Smart Showing™ device (Raspberry Pi)
- Power cable
- Ethernet cable (included)
- Smartphone (iPhone or Android)
- Property Wi-Fi name and password

---

# 🔌 Step 1 – Connect the Device

1. Plug the Smart Showing™ device into power.
2. Connect the Ethernet cable from the device to the property’s router.
3. Wait **2–3 minutes** for the system to fully start.

No additional configuration is required at this stage.

---

# 📱 Step 2 – Install the Home Assistant App

Smart Showing™ runs on the official Home Assistant platform.

Download the app:

### 🍎 iPhone / iPad  
https://apps.apple.com/app/home-assistant/id1099568401

### 🤖 Android  
https://play.google.com/store/apps/details?id=io.homeassistant.companion.android

Official website:  
https://www.home-assistant.io/

---
# 🔎 Step 3 – Connect to Your Smart Showing™ System

You can connect using either the mobile app **or** a computer web browser.

---

## 📱 Option A – Using the Home Assistant App

1. Open the Home Assistant app.
2. It should automatically detect:

   **Smart Showing™ (http://smartshowing.local)**

3. Tap the detected server.
4. Log in using the credentials provided with your Smart Showing™ kit.

---

## 💻 Option B – Using a Computer or Browser

1. Make sure your phone, tablet, or computer is connected to the same network.
2. Open a web browser.
3. Enter:

   **http://smartshowing.local**

4. Log in using the credentials provided with your Smart Showing™ kit.

---

### If the system does not appear automatically:

- Confirm the Ethernet cable is connected.
- Make sure your device is on the same network.
- Try entering the IP address assigned by your router  
  (example: `http://192.168.1.25`)

---

# 📶 Step 4 – Connect to Property Wi-Fi

Inside the app:

1. Tap **Settings**
2. Select **System**
3. Select **Network**
4. Choose **Wi-Fi**
5. Select the property Wi-Fi network
6. Enter the Wi-Fi password
7. Tap **Save**

After saving:

- Wait 1–2 minutes
- Unplug the Ethernet cable

Your Smart Showing™ system is now running fully on Wi-Fi.

---

# ✅ Step 5 – Test the System

Walk into the entry area.

You should see:

- Lights activate
- Welcome message play
- Dashboard visible in the app

Your property is now ready for showings.

---

# 🔁 Moving to Another Property?

Repeat these steps:

1. Plug in Ethernet
2. Open the app
3. Change Wi-Fi network
4. Remove Ethernet

---

# 🆘 Need Help?

If the system does not connect:

- Confirm the router is powered on
- Check that the Ethernet cable is securely connected
- Restart the Smart Showing™ device
