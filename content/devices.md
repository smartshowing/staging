---
title: "Devices Used"
---

The Smart Showing Kit is designed to reduce the time and physical presence typically required from agents during showings.  
Each device included in the system directly supports remote access, remote awareness, or remote confirmation.

Together, these devices allow qualified showings to occur without an agent needing to be on site for every visit.

## Remote Lockbox

A remote lockbox enables controlled access to the property without requiring an agent to be physically present.

It supports:
- Secure, permission-based entry
- Remote verification that access occurred
- Reduced travel time for routine showings

This device is foundational to remote showings.

## Entry / Exit Presence Sensor

An entry / exit presence sensor confirms when someone enters and leaves the property.

It allows the agent to:
- Verify that a showing has started
- Confirm when the property has been vacated
- Maintain accountability without being on site

This replaces manual check-ins and follow-up visits.

## Doorbell Alert Sensor

A doorbell alert sensor provides immediate awareness when someone arrives at the property.

It supports:
- Real-time confirmation of arrival
- Remote acknowledgment of visitors
- Visibility into unexpected access attempts

This allows an agent to remain informed without attending the showing.

## Interior Presence Sensors

Interior presence sensors are placed in key common areas such as living rooms or family rooms.

They allow the agent to:
- Confirm that visitors are actively viewing the property
- Distinguish between brief entry and a full showing
- Detect unexpected activity outside scheduled windows

These sensors provide confidence that the showing is proceeding as intended.

## Cameras (When Applicable)

In some configurations, cameras are used in limited, clearly disclosed areas such as entry points or garages.

When used, cameras allow the agent to:
- Verify entry and exit remotely
- Confirm that the property is secure after a showing
- Resolve questions without returning to the property

Cameras are never placed in private areas.

## Accent Lighting

Accent lighting provides subtle visual confirmation and guidance during remote showings.

Lighting may be used to:
- Indicate that the system is active
- Support visibility in low-light conditions
- Reinforce presence without intervention

This improves the showing experience while requiring no agent involvement.

## Audio Notification Speaker

An audio notification speaker may provide brief, neutral cues related to system state.

These cues help:
- Reinforce accountability
- Confirm entry or exit events
- Support remote oversight without confrontation

Audio notifications are informational and non-disruptive.

## Control Hub

A compact control hub coordinates all system components and enables remote management.

The hub:
- Requires no interaction from the seller
- Allows the system to operate continuously
- Is installed and removed as part of the service

## Why This Matters for Agents

By enabling verified access, interior awareness, and remote confirmation, these devices allow agents to:
- Reduce on-site visits
- Avoid unnecessary travel
- Manage multiple listings more efficiently
- Support showings without being physically present

This is how the system offsets its setup and monthly cost—by saving agent time at scale.
